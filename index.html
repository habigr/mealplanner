Anthropic API Key

      
Used for AI-powered features like recipe parsing. Stored on this device only — never synced to Firebase or shared.

      

      

        
        

          
          
        

      

      

        
        
      

      
Get a key at console.anthropic.com → API Keys. Costs fractions of a cent per recipe parse.

    

    

      
Recipe Image Search

      
Auto-finds a photo for recipes that have none. Order: the recipe's own URL photo → Spoonacular (recipe match) → Google (catches niche dishes). Keys stick with the TRIP, so all devices/users get them. Found images save to Firebase.

      

        
        
        
 

      

      

        
        
        

      

      

        
        
      

      
Spoonacular (recipe matches): spoonacular.com/food-api. Pexels (catches niche dishes): one key at pexels.com/api — no setup. Both stick with the trip. "Backfill" fills up to 25 image-less recipes at a time.
