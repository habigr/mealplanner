Ingredient Editor — new approach

The fix for “clunky”: stop cramming 8 controls into every row. The list reads like a recipe and stays calm; the edit controls appear only when you tap a row. Four takes below.

← swipe to compare all 4 →

Idea A
Reads like a recipe · tap to edit
Collapsed, each line is just “2 bottles champagne.” Tap one and it opens a clean inline editor (stepper, unit, where-it-buys). One row open at a time.

My pick: Idea A — the list reads like an actual recipe, and tapping a row reveals a tidy inline editor with a –/+ stepper (no keyboard) and everything in plain language.
